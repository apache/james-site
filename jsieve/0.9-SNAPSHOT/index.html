Apache James jSieve

What is jSieve?

jSieve is a Java implementation of the Sieve mail filtering language defined by RFC 5228. jSieve is implemented as a language processor that can be plugged into any internet mail application to add Sieve support.

jSieve is a subproject of Apache JAMES. All who are interested in developing jSieve and JAMES will be warmly welcomed on the mailing lists.

jSieve consists of two products:

  • Apache JSieve is a Sieve library coded in Java. See Getting Started, Usage and Sieve Features.

  • Apache JSieve Utilities contains utility classes helpful when using Sieve but not considered sufficiently core to be included in the main library.

What is Sieve?

Sieve is an extensible mail filtering language. Its limited expressiveness (no loops or variables, no tests with side effects) allows user created scripts to be run safely on email servers. Sieve is targeted at the final delivery phase (where an incoming email is transferred to a user’s mailbox).

Sieve scripts are composed of commands. Control commands manage the execution of the script. Test commands define side-effect free criteria. Action commands are mail operations to be performed.

Extensions Supported

Body Extension

RFC 5173 (Sieve Email Filtering: Body Extension) describes an extension command that tests the body of an email for one or more strings.

Sieve-In-Xml
